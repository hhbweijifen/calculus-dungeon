【游戏概述】
这是一款数学主题的Roguelike卡牌地牢探险游戏。
你扮演伟大的数学家（欧拉、高斯、洛必达、黎曼、柯西、拉格朗日），
使用微积分的力量击败怪物，拯救发散的世界。

═══════════════════════════════════════════════════════════
  📁 文件说明
═══════════════════════════════════════════════════════════

• 微积分地牢-史诗版.html    ← 游戏本体（双击即玩！）
• start_server.py            ← 本地服务器脚本（支持手机访问）

═══════════════════════════════════════════════════════════
  🚀 运行方式
═══════════════════════════════════════════════════════════

【方式一：电脑直接玩（最简单）】
直接双击 "微积分地牢-史诗版.html" 文件，
系统会自动用浏览器打开，即可开始游戏。

【方式二：手机/平板玩（需要局域网）】
1. 确保手机和电脑连接同一个WiFi
2. 双击运行 "start_server.py"
3. 脚本会显示一个局域网地址，例如：http://192.168.1.5:8080
4. 在手机浏览器中输入这个地址
5. 开始游戏！

【方式三：添加到手机主屏幕（像App一样）】
• iPhone (Safari)：分享按钮 → "添加到主屏幕"
• Android (Chrome)：菜单 → "添加到主屏幕"
添加后，游戏会像原生App一样从桌面图标启动，
支持离线运行，全屏显示，没有浏览器地址栏！

═══════════════════════════════════════════════════════════
  💾 存档系统说明
═══════════════════════════════════════════════════════════

本游戏使用浏览器的 localStorage 本地存储技术保存进度。

✅ 自动存档：
   • 游戏会自动在关键节点保存进度
   • 主菜单的"继续冒险"按钮可读取存档

✅ 手动备份/迁移：
   • 游戏中打开"设置" → "导出存档"
   • 存档数据会复制到剪贴板
   • 在新设备上打开"设置" → "导入存档"即可恢复

⚠️ 注意事项：
   • 存档保存在当前浏览器的本地存储中
   • 清除浏览器数据会导致存档丢失
   • 建议定期导出存档作为备份
   • 不同浏览器之间的存档不互通
